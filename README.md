# Halloween Projection 2026

ハロウィンのプロジェクションマッピング用シーンを、ブラウザ上で全画面ループ再生する Web アプリです。
ここで作った映像をビデオキャプチャーして MadMapper に送り、投影面へのマッピングは MadMapper 側で行います。

ビルド不要・外部素材不要です（絵は Canvas で描画し、SE は WebAudio で合成しています）。

## 起動

`index.html` を Chrome / Edge で開くだけで動きます（`file://` で OK）。
ローカルサーバーで開いても構いません。

```bash
python3 -m http.server 8000
```

- 編集モード: `http://localhost:8000/`
- ショーモードで直接起動: `http://localhost:8000/?show`（`&scene=2` で 2 番目のシーンから開始）

> ブラウザの自動再生制限のため、音はページを一度クリックするかキーを押してから鳴ります。
> 無人運用する場合は、Chrome を `--kiosk --autoplay-policy=no-user-gesture-required` 付きで起動してください。

## GitHub Pages で公開

公開 URL: https://kobashi.github.io/Helloween2026/
（ショーモードで直接開く場合は https://kobashi.github.io/Helloween2026/?show ）

`.github/workflows/pages.yml` が push のたびにサイトをデプロイします。
最初の 1 回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
設定後、Actions タブの「Deploy to GitHub Pages」を手動で実行（Run workflow）するか、もう一度 push すると公開されます。

- 編集内容は、開いているブラウザ（オリジン）ごとに localStorage へ保存されます。ローカルで編集した内容を Pages 版で使うときは、JSON を書き出して読み込んでください。
- 会場がオフラインなら、Pages ではなくローカルの `index.html` を使ってください。ネットがない場合、看板のフォント（Google Fonts）だけが代替フォントになります。

## モード

### 編集モード
- **シーン**: 追加・複製・並べ替え・削除。シーンごとに名前、再生時間（秒）、背景テーマを設定します。チェックを外したシーンはショーで飛ばされます。
- **キャラクター / オブジェクトの配置**: パレットから追加し、ドラッグで移動します。黄色のハンドルかマウスホイールでサイズを変え、`F` で左右反転します。
- **プレビュー**: `Space` かキャンバスのダブルクリックで、選択中のシーンだけを物理演算と FSM 付きでループ再生します。
- **全画面で編集**: 「⛶ 全画面」か `Shift+F` で、編集モードのまま全画面にできます。全画面ではキャンバスがショーと同じ位置・大きさで表示され、ツールバーとパネルはその上に重なります。`Tab`（または「UIを隠す」）で UI を隠すと投影と同じ表示になり、プロジェクターの映像を見ながらドラッグで領域・障害物・キャラを合わせられます。もう一度 `Tab` で UI が戻ります。
- **自動保存**: 編集内容はブラウザ（localStorage）に保存されます。別の PC へは「書き出し」した JSON を「読み込み」で移します。

### ショーモード
「ショー開始」を押すと全画面になり、有効なシーンを順に再生し、フェードを挟んでループし続けます。

| キー | 動作 |
|---|---|
| Esc / E | 編集モードへ戻る（`E` なら全画面のまま編集へ。全画面中の Esc は、まず全画面を解除します） |
| ← / → | 前 / 次のシーンへ |
| Space | 一時停止 |
| G | 領域・障害物のガイドを表示（投影位置合わせ用） |
| F | 全画面の切り替え |
| M | 消音 |

マウスを動かすと操作ヒントとカーソルが 2.5 秒だけ表示されます。

## 移動領域と障害物（マッピング用）

現実の投影面に合わせて設定する透明なボックスです。**全シーン共通**で、ショー中は表示されません（`G` キーで確認できます）。

- **移動領域**: キャラクターが動ける範囲です。複数置けて、領域の和集合の内側が移動可能な空間になります。
  - 種類: `共通`（全キャラ） / `地上`（重力のあるキャラだけ） / `空中`（飛ぶキャラだけ）
  - 領域が接したり重なったりしていれば、キャラクターは歩いて・飛んで行き来します。
  - 離れた領域へは、地上キャラは放物線ジャンプで、空中キャラは曲線を描いて飛んで移動します。「他領域からの移動先にする」をオフにすると、その領域は移動先に選ばれません。
- **障害物ボックス**: 現実の物（柱、箱、植木など）に重なる場所に置きます。キャラクターはそこを通り抜けず、上に乗ったり、ジャンプで越えたり、引き返したりします。

領域ロックをオンにすると、キャラを動かすときに領域を誤って掴まなくなります。

## キャラクター（FSM）

| キャラ | 種類 | 主なステート |
|---|---|---|
| おばけ | 空中 | ただよう / BOO!（膨らむ） / 透明化 / 領域移動 |
| コウモリ | 空中 | 羽ばたき / 急降下 / 天井にぶら下がる / 領域移動 |
| 魔女 | 空中 | 巡航 / 宙返り / 高笑い（キラキラ） / ターン / 領域移動 |
| クモ | 空中 | 糸でぶら下がる / 落下 / 登る / 天井を歩く / 領域移動 |
| 黒猫 | 地上 | 座る（ニャー） / 歩く / 走る / ジャンプ / 威嚇 / ターン / 領域ジャンプ |
| ジャック（かぼちゃ） | 地上 | 待機 / ぴょんぴょん / 大ジャンプ回転 / ターン / 領域ジャンプ |
| ガイコツ | 地上 | 歩く / ダンス / バラバラ→復活 / ジャンプ / ターン / 領域ジャンプ |

地上キャラは壁や障害物に当たると、越えられる高さならジャンプし、越えられなければ振り向きます。
キャラごとに、サイズ倍率・速さ倍率・SE のオン/オフ・左右の向きを設定できます。

## 背景テーマ

墓場の月夜 / 幽霊屋敷（雷） / かぼちゃ畑 / 魔女の森 / 赤い月 / 星空のみ / 黒（実物投影用）

投影でメリハリが出るように、暗い背景に彩度の高いオレンジ・紫・緑・白を使っています。
黒いキャラクター（猫・コウモリ・クモ）は、黒が投影されない（光らない）ことを考えて、明るい輪郭線と光る目で描いています。
「輪郭線」と「発光の強さ」はプロジェクト設定で調整できます（発光を 0 にすると描画が軽くなります）。

## SE

ジャンプ、着地、BOO、コウモリの鳴き声、ニャー、威嚇、魔女の高笑い、骨のカタカタ、雷、フクロウ、大釜の泡、シーン切り替えの風切り音。
左右のパンはキャラクターの位置に追従します。音量、SE のオン/オフ、環境音（風）はプロジェクト設定で変えられます。

## MadMapper への送り方

1. プロジェクト設定の「出力解像度」を、キャプチャー / 出力する解像度に合わせます（例: 1920×1080）。
2. ショーモードで全画面再生します。
3. 次のどれかで MadMapper に送ります。
   - **HDMI キャプチャー**: 再生 PC の出力をキャプチャーデバイスで取り込み、MadMapper のビデオ入力として使います。
   - **同じ PC でキャプチャー**: OBS などでブラウザ画面をキャプチャーし、Syphon（macOS）/ Spout（Windows）/ NDI で MadMapper に渡します。
4. MadMapper 側で投影面に合わせて変形します。移動領域と障害物の位置合わせは、ショー中に `G` キーでガイドを出して調整します。

## ファイル構成

```
index.html        UI
css/style.css
js/util.js        共通処理・パレット
js/audio.js       WebAudio による SE 合成
js/physics.js     軽量 AABB 物理（領域の和集合・障害物・重力・接地）
js/fsm.js         有限状態機械
js/characters.js  動くキャラクター（FSM と描画）
js/props.js       静的オブジェクト
js/themes.js      背景テーマ
js/stage.js       シーンのランタイム（更新・描画・パーティクル）
js/project.js     初期データ・保存・読み込み
js/main.js        メインループ、編集モードとショーモード
js/editor.js      エディタ UI
```

座標系は高さ 1080 固定で、幅は出力解像度のアスペクト比から決まります（16:9 なら 1920×1080）。
